
Rzut kostką

Prosta aplikacja Android napisana w Javie.

Funkcje
- Losowanie liczby od 1 do 6.
- Liczenie wykonanych rzutów.
- Czyszczenie wyniku.
- Resetowanie aplikacji.
- Komunikat Toast przy próbie wyczyszczenia wyniku przed rzutem.

Obsługa przycisków
- Rzuć kostką – android:onClick.
- Wyczyść wynik i Reset – wspólny setOnClickListener.
